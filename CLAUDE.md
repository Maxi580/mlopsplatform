## Scope and simplicity

This is a small internal platform for one team. Keep the architecture and requirements as simple as possible; prefer the boring solution.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on Maxi580/mlopsplatform, using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the five default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
